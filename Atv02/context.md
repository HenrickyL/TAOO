Exercício 2: Projeto e Implementação de um Sistema de Estacionamento
Contexto
Um estacionamento deseja desenvolver um sistema para registrar os veículos que utilizam o local e calcular o valor devido por cada um deles.

O estacionamento recebe dois tipos de veículos:

carros;

motocicletas.

Embora todos os veículos possuam algumas informações em comum, como placa e quantidade de horas estacionadas, cada tipo de veículo possui uma regra própria para o cálculo do valor da permanência.

O desenvolvimento do exercício será dividido em duas etapas.

Etapa 1: Projeto UML
Antes de implementar o programa, você deverá elaborar um Diagrama de Classes UML representando a estrutura proposta para o sistema.

O diagrama deverá apresentar, no mínimo, as classes:

Veiculo;

Carro;

Motocicleta;

Estacionamento.

Para cada classe, represente no diagrama:

seus principais atributos;

suas principais operações (métodos);

as relações de herança existentes;

a relação entre o estacionamento e os veículos armazenados.

O diagrama deve permitir compreender como o sistema será estruturado antes da implementação.

Você pode utilizar qualquer ferramenta de modelagem UML. Algumas opções disponíveis na Web são:

diagrams.net (Draw.io);

Lucidchart;

O diagrama deverá ser exportado para o formato PDF.

Entrega da Etapa 1
O arquivo PDF contendo o Diagrama de Classes UML deverá ser entregue separadamente do código-fonte.

O modelo apresentado no diagrama deve corresponder, tanto quanto possível, à estrutura posteriormente implementada no programa.

Etapa 2: Implementação
Após elaborar o projeto UML, implemente o sistema representado no diagrama.

Além de implementar corretamente as classes e os relacionamentos definidos no projeto, o programa deverá seguir exatamente as regras de negócio, entrada e saída especificadas a seguir, pois o código será submetido à correção automática. Essas informações estão melhor descritas na atividade disponível no VPL.

Entrega da Etapa 2
Deve ser avaliado (pelo botão de Avaliar do VPL) o código-fonte correspondente ao projeto elaborado e que respeite todas as regras de negócio, entrada e saída descritas no enunciado do VPL.

O objetivo é que a modelagem UML seja utilizada como uma etapa de projeto da solução, servindo de base para a implementação das classes e de seus relacionamentos. Portanto, é importante que seu projeto UML esteja em concordância com a sua implementação.
